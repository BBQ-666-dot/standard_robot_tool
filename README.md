# 串口调试助手

## 介绍
串口调试助手，接受c板的数据并以图像形式展现出来

配套使用的USB通信部分的代码文件：[USB串口通信模块](https://gitee.com/SMBU-POLARBEAR/electric-control/tree/master/Microcontroller_Module/USB_Serial_Communication_Module)

## 改进方向
1. 绘制3维图的功能
2. 显示整车状态
3. 可以缩放与拖动图像
4. 可以添加检测单片机是否可以通信，即协议是否正确。
5. 添加数据检查功能，忽略协议信息，直接输出串口接收到的数据进行分析。

## 开始使用
### 串口设置
1. 选择连接到电脑上的串口。
2. 选择合适的波特率（一般不用改，默认的9600基本够用）

### 读取数据
- 点击打开串口，当前面的方块显示为绿色时即串口已经开启，并且开始读取数据和显示数据了。

### 增减采样点个数
- 鼠标点击采样点个数的输入框直接更改，或使用滚轮滚动更改。

### 输出图像
- 选择你想要看的数据标签，图像即会显示一段时间内该数据的变化情况的图线。
